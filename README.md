# Интеграция ИСУР-Проекты ↔ Битрикс24

Синхронизация задач между ИСУР-Проекты и Битрикс24.

---

## Что синхронизируется

| Направление | Данные |
|---|---|
| ИСУР → Битрикс | Создание и обновление задач, крайний срок, родительские связи, исполнители |
| Битрикс → ИСУР | Статус завершения, дата фактического окончания |

---

## Требования

| Компонент | Версия |
|---|---|
| Python | 3.8 или выше |
| Операционная система | Windows / Linux / macOS |
| Доступ в интернет | Для работы с API ИСУР и Битрикс24 |
| Сервер (опционально) | Для приёма вебхуков (публичный URL) |

---

## Настройка

### 1. Получить вебхук Битрикс24

В Битрикс24 → **Приложения** → **Входящие вебхуки** → **Создать**.

Права: `task`, `sonet_group`, `user`, `tasks_extended`.

### 2. Создать `.env`

```bash
cp .env.example .env
```

Заполнить своими данными

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Запустить

```bash
python -m src.main
```

---

## Остановка

Нажмите `Ctrl + C` в терминале.

## Структура проекта

```
src/
├── clients/          # API-клиенты (ИСУР, Битрикс24)
├── sync/             # Логика синхронизации
├── webhook/          # Обработка исходящих вебхуков
├── utils/            # БД, логирование, настройки
├── config.py         # Загрузка .env
├── exceptions.py     # Кастомные ошибки
├── logger.py         # Настройка логирования
└── main.py           # Точка входа
```

## Расписание

| Задача | Интервал |
|---|---|
| Прямая синхронизация (ИСУР → Битрикс) | Каждые 30 минут |
| Резервная сверка (Битрикс → ИСУР) | Раз в сутки (время из `.env`) |
| Вебхуки (Битрикс → ИСУР) | Мгновенно |

---

## Настройка исходящего вебхука

В Битрикс24 → **Приложения** → **Исходящие вебхуки** → **Создать**.

- **URL:** `https://ваш-сервер.ru/webhook`
- **События:** `ONTASKUPDATE`, `ONTASKCOMPLETE`
