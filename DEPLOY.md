# Развёртывание интеграции ИСУР-Проекты ↔ Битрикс24

Документ для администраторов и тестировщиков. Описывает установку, настройку и запуск интеграционного сервиса.

---

## 📦 Требования

| Компонент | Версия |
|---|---|
| Python | 3.8 или выше |
| Операционная система | Windows / Linux / macOS |
| Доступ в интернет | Для работы с API ИСУР и Битрикс24 |
| Сервер (опционально) | Для приёма вебхуков (публичный URL) |

---

## 🚀 Установка

### 1. Скачать код

```bash
git clone https://github.com/ваш-репозиторий/isur-bitrix-integration.git
cd isur-bitrix-integration
```

### 2. Создать виртуальное окружение

```bash
python -m venv .venv
source .venv/bin/activate      # Linux / Mac
.venv\Scripts\activate         # Windows
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

---

## ⚙️ Настройка

### 4. Создать файл .env

Скопируй шаблон и заполни своими данными:

```bash
cp .env.example .env
```

Отредактируй `.env`:

```env
# === ИСУР-Проекты ===
ISUR_LOGIN=Admin
ISUR_PASSWORD=ваш_пароль
ISUR_AUTH_URL=https://ваш-сервер.api.isur.tech/api/Authorization
ISUR_API_URL=https://ваш-сервер.api.isur.tech/api/Works
ISUR_WORK_PARTICIPANTS_URL=https://ваш-сервер.api.isur.tech/api/WorkParticipants

# === Битрикс24 ===
BITRIX_WEBHOOK=https://ваш-портал.bitrix24.ru/rest/1/токен/
GROUP_ID=0
RESPONSIBLE_ID=1

# === Время резервной сверки ===
RESERVE_SYNC_TIME=03:00
```

### 5. Проверить структуру проекта

Убедись, что папка `src/` и файлы на месте. База данных `sync.db` создастся автоматически при первом запуске.

---

## ▶️ Запуск

### 6. Запустить интеграцию

```bash
python -m src.main
```

Программа:

- Запустит таймер (прямая синхронизация каждые 30 минут)
- Запустит веб-сервер для приёма вебхуков (порт 5000)

### 7. Настроить исходящий вебхук в Битрикс24

1. Зайди в Битрикс24 → **Приложения** → **Исходящие вебхуки** → **Создать**
2. Укажи URL: `https://твой-сервер.ru/webhook`
3. Выбери события: `ONTASKUPDATE`, `ONTASKCOMPLETE`
4. Сохрани

---

## 🧪 Проверка работы

### 8. Проверить логи

Логи пишутся в `logs/sync.log`. Проверь, что синхронизация запускается:

```bash
tail -f logs/sync.log   # Linux / Mac
type logs\sync.log      # Windows
```

### 9. Проверить вебхуки

1. Заверши задачу в Битрикс24
2. Проверь логи — должно появиться сообщение о полученном вебхуке
3. Проверь, что задача закрылась в ИСУР

### 10. Проверить резервную сверку

Резервная сверка запускается раз в сутки в указанное время (из `.env`). В логах появится:

```
🔄 ЗАПУСК РЕЗЕРВНОЙ СВЕРКИ
✅ Закрыта задача ... (сверка)
```

## ❗ Возможные проблемы

| Проблема | Решение |
|---|---|
| `ModuleNotFoundError` | Проверь, что установлены все зависимости |
| `Invalid URL 'None'` | Проверь `.env` — все переменные должны быть заполнены |
| Вебхук не приходит | Проверь URL в настройках Битрикс24, доступность сервера |
| База данных заблокирована | Закрой другие программы, работающие с `sync.db` |
