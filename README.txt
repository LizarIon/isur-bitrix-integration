# Интеграция ИСУР-Проекты ↔ Битрикс24

Программа синхронизирует задачи между системами ИСУР-Проекты и Битрикс24.

## Возможности

| Направление | Что делает |
|---|---|
| ИСУР → Битрикс | Создаёт и обновляет задачи, крайний срок, родительские связи |
| ИСУР → Битрикс | Добавляет исполнителей (участников) через email |
| Битрикс → ИСУР | Закрывает завершённые задачи в ИСУР |

## Особенности синхронизации

**Для полной синхронизации выполните два последовательных запуска:**

1. **Первый запуск** — создаются все задачи в Битрикс24
2. **Второй запуск** — обновляются данные и устанавливаются родительские связи

> Если вы используете планировщик (например, каждые 30 минут), то родительские связи установятся автоматически при втором автоматическом запуске.

## Требования

- Python 3.8 или выше
- Установленные библиотеки:

```bash
pip install requests schedule

Доступ к API ИСУР-Проекты
Вебхук Битрикс24 (входящий)


Настройка
1. Получите вебхук Битрикс24
Зайдите в ваш Битрикс24 → Приложения → Входящие вебхуки → Создать вебхук

Выберите права: task, sonet_group, user, tasks_extended

Скопируйте ссылку вида: https://ваш-портал.bitrix24.ru/rest/1/токен/


2. Настройте файл sync.py
Откройте sync.py в любом текстовом редакторе и найдите раздел «НАСТРОЙКИ». Заполните:
# Данные для входа в ИСУР-Проекты
ISUR_LOGIN = "Admin"
ISUR_PASSWORD = "ваш_пароль"

# URL API ИСУР-Проекты
ISUR_AUTH_URL = "https://ваш-сервер.api.isur.tech/api/Authorization"
ISUR_API_URL = "https://ваш-сервер.api.isur.tech/api/Works"
ISUR_WORK_PARTICIPANTS_URL = "https://ваш-сервер.api.isur.tech/api/WorkParticipants"

# Вебхук Битрикс24
BITRIX_WEBHOOK = "https://ваш-портал.bitrix24.ru/rest/1/токен/"

# ID проекта в Битрикс24 (0 — без группы)
GROUP_ID = 0

# ID ответственного по умолчанию (1 — Admin)
RESPONSIBLE_ID = 1

Важно: URL сотрудников (/api/Employees) жёстко прописан в коде. Если ваш сервер отличается, замените studldn7.api.isur.tech на свой адрес.


3. Убедитесь, что у сотрудников в ИСУР есть email
Для синхронизации исполнителей:

В Битрикс24 у пользователя должен быть заполнен email

В ИСУР у сотрудника должен быть тот же email (заполняется вручную через интерфейс ИСУР)

Запуск
python sync.py

Программа сразу выполнит одну синхронизацию, затем продолжит работать по расписанию.

Остановка: нажмите Ctrl + C

Настройка расписания
В конце файла sync.py найдите строку:
schedule.every(30).minutes.do(sync_bidirectional)
Примеры настройки
Расписание			Код
Каждые 5 минут			schedule.every(5).minutes.do(sync_bidirectional)
Каждый час			schedule.every().hour.do(sync_bidirectional)
Каждый день в 9:00		schedule.every().day.at("09:00").do(sync_bidirectional)
Каждый понедельник в 10:00	schedule.every().monday.at("10:00").do(sync_bidirectional)
Каждые 2 часа			schedule.every(2).hours.do(sync_bidirectional)

Файлы программы
Файл			Назначение
task_links.json		Связи ID задач (ИСУР ↔ Битрикс)
task_data.json		Копия данных из ИСУР (для отладки)
closed_in_isur.json	Уже закрытые в ИСУР задачи
Все файлы создаются автоматически при первом запуске.

Возможные ошибки
Ошибка					Решение
Read timed out				Увеличьте интервал синхронизации до 30–60 минут
Expecting value: line 1 column 1	Перезапустите программу или проверьте доступность сервера ИСУР
Сотрудник не найден			Проверьте email в ИСУР и Битрикс24
